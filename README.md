# Smart Log File Analyzer

## Project Description
Smart Log File Analyzer is a Python-based project designed to analyze log files and identify different types of log messages such as INFO, WARNING, and ERROR.

The program reads a log file, counts different log levels, identifies the most frequent error, and generates an analysis report automatically.

## Features
- Reads and analyzes log files
- Identifies INFO, WARNING, and ERROR messages
- Counts different types of log entries
- Finds the most frequent error
- Generates an analysis report
- Displays the total number of log entries analyzed

## Technologies Used
- Python
- File Handling
- Functions and Modules

## Project Files
- `main.py` - Main program
- `log_analyzer.py` - Contains log analysis functions
- `sample_log.txt` - Sample log file used for analysis
- `report.txt` - Stores the generated analysis report
- `utils` - Utility package

## How to Run
1. Download or clone the project.
2. Open the project folder in VS Code.
3. Run `main.py`.
4. The program analyzes `sample_log.txt`.
5. View the generated results in `report.txt`.
